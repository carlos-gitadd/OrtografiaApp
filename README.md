# 📚 OrtografíaApp

### Videojuego educativo 3D

## 📖 Descripción del proyecto

OrtografíaApp es un videojuego educativo desarrollado en Unity 3D, dirigido a estudiantes de tercer grado de primaria. Su finalidad es fortalecer el aprendizaje de las reglas ortográficas, especialmente la identificación de palabras agudas y graves.

El videojuego consiste en controlar un automóvil que debe encontrar las vocales necesarias para completar palabras y superar diferentes desafíos educativos.

## 🎯 Objetivo

Fortalecer el aprendizaje de las reglas de acentuación mediante actividades interactivas que permitan reconocer y diferenciar palabras agudas y graves.

## 🎮 Características del videojuego

- Desarrollado en Unity 3D.
- Contiene tres niveles.
- Control de un automóvil.
- Búsqueda de vocales para completar palabras.
- Clasificación de palabras agudas y graves.
- Retos y obstáculos.
- Sistema de puntuación.
- Retroalimentación y recompensas.

## 🛠️ Tecnologías utilizadas

- Unity 3D: desarrollo del videojuego.
- C#: programación.
- Visual Studio Code: edición de código.
- Git y GitHub: control de versiones.
- HTML y CSS: desarrollo del sitio web.

## 💻 Requisitos del sistema

### Requisitos mínimos
- Sistema operativo: Windows 10 de 64 bits.
- Procesador: Intel Core i3 o equivalente.
- Memoria RAM: 4 GB.
- Gráficos compatibles con DirectX 11.
- Espacio disponible: 2 GB.

### Requisitos recomendados
- Sistema operativo: Windows 10 o Windows 11 de 64 bits.
- Procesador: Intel Core i5 o equivalente.
- Memoria RAM: 8 GB.
- Gráficos compatibles con DirectX 11.
- Espacio disponible: 4 GB.

*Nota: Los requisitos son estimados y deben verificarse con la versión final del videojuego.*

## 🚀 Cómo ejecutar el proyecto

1. Descargar el repositorio.
2. Instalar Unity Hub.
3. Abrir Unity Hub.
4. Seleccionar la opción de agregar proyecto.
5. Buscar la carpeta de OrtografíaApp.
6. Abrir el proyecto con la versión de Unity correspondiente.
7. Ejecutar el videojuego.
